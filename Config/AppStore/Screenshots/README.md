# Screenshot Staging

Store screenshots must use sanitized demo data only.

Do not include:

- real customer credentials or tokens,
- private project names,
- private animal/device aliases,
- exact active field locations,
- browser tabs or background windows containing sensitive telemetry,
- personal email addresses unless they are demo accounts.

Recommended screenshot set:

- first-run setup with the token field empty,
- filters view with demo project/device names,
- compact top-center companion panel with demo check-ins,
- main detail window with demo map coordinates,
- notifications settings.
